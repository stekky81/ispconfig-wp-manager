# Security policy

WPStation runs commands as root on web servers, so security reports are welcome and handled first.

## Reporting

Please **do not open a public issue**. Report it privately on GitHub:
[Security → Report a vulnerability](https://github.com/stekky81/ispconfig-wpstation/security/advisories/new).
Include what an attacker needs (for example a client account of the panel, or a WordPress admin of one site) and
what they get.

Fixes are released as soon as they are ready, and the report is credited unless you prefer otherwise.

## Supported versions

WPStation is pre-release: only the latest commit of `main` gets fixes.

## Design

The security review, the threat model and what is still open are in [docs/security.md](docs/security.md).
